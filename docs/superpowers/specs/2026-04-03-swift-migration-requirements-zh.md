## 1. 产品概述

### 1.1 产品名称
PaperTok Reader（原生 Swift iOS/macOS 版）

### 1.2 产品愿景
一款面向 iOS 和 macOS 的高品质电子书阅读器，集成学术论文发现、AI 驱动的对话/分析以及全面的阅读管理功能——以 SwiftUI 原生 Apple 平台应用的形式重新构建。

### 1.3 目标平台
- iOS 17.0+（iPhone + iPad）
- macOS 14.0+（Sonnet）

### 1.4 Bundle ID
`ai.papertok.paperreader`（沿用 Flutter 版本）

  - 通过拖放导入（iPad/Mac）

- **模式 B：目录扫描（新增）**

  - 设置界面：管理监控目录（添加/移除）
  - 被标记目录不可用时优雅处理
- 两种模式共存；用户可混合使用导入和扫描的图书
- 验收标准：沙盒导入功能不变；目录扫描无需复制即可发现图书；新书自动出现

## 3. 非功能性需求

### NFR-01: 性能
- 应用启动 < 2 秒
- EPUB 翻页 < 100ms
- AI 流式首 token < 500ms（API 响应后）
- 1000 本书的图书馆搜索 < 200ms

### NFR-02: 安全性
- API 密钥存储在 Keychain 中（绝不使用 UserDefaults）
- WebDAV 同步排除 api_key
- 明文备份排除敏感信息
- 加密备份使用 AES-256

### NFR-03: 无障碍
- 所有页面支持 VoiceOver
- Dynamic Type 支持
- 最小触摸目标 44pt
- 颜色对比度 ≥ 4.5:1

### NFR-04: 离线支持
- 所有阅读功能离线可用
- AI 对话优雅降级（显示错误提示）
- FTS5 搜索离线可用（向量搜索需要嵌入）

### NFR-05: 数据完整性
- 多步操作使用数据库事务
- 恢复前验证备份
- 同步使用原子文件替换
