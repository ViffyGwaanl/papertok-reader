**日期：** 2026-04-03
**类型：** 完整 1:1 迁移 + Apple 风格 UI 重新设计
**来源：** Flutter 项目分析（551+ 个 Dart 文件、217 个服务、47 个页面、46 个 AI 工具）

---

## 1. 产品概述

### 1.1 产品名称
PaperTok Reader（原生 Swift iOS/macOS）

### 1.2 产品愿景
一款面向 iOS 和 macOS 的高端电子书阅读器，集成学术论文发现、AI 驱动的对话/分析以及全面的阅读管理功能——以 SwiftUI 重建为原生 Apple 平台应用。

### 1.3 目标平台
- iOS 17.0+（iPhone + iPad）
- macOS 14.0+（Sonnet）

### 1.4 Bundle ID（保持不变）
`ai.papertok.paperreader`（从 Flutter 迁移保留）

## 3. 非功能性需求

### NFR-01：性能
- 应用启动时间 < 2 秒
- EPUB 翻页 < 100ms
- API 响应后 AI 流式传输首 token < 500ms
- 1000 本书书库搜索 < 200ms

### NFR-02：安全性
- API 密钥存储在 Keychain 中（绝不存入 UserDefaults）
- WebDAV 同步排除 api_key
- 普通备份排除密钥
- 加密备份使用 AES-256

### NFR-03：无障碍访问
- 所有屏幕支持 VoiceOver
- Dynamic Type 支持
- 最小触摸目标 44pt
- 颜色对比度 ≥ 4.5:1

### NFR-04：离线支持
- 所有阅读功能可离线使用
- AI 对话优雅降级（显示错误）
- FTS5 搜索可离线使用（向量搜索需要嵌入）

### NFR-05：数据完整性
- 多步骤操作使用数据库事务
- 恢复前验证备份
- 同步时原子文件替换
