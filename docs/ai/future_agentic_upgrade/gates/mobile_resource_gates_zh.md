# Mobile Resource Gates

## 1. Pre-Gate

移动端长任务、sub-agent、索引、图谱生成和多模型调用必须先确认：

- 是否能取消。
- 是否能重试。
- 是否有用户可见进度。
- 是否限制并发。
- 是否记录失败原因。
- 是否能在断线或重启后恢复到一致状态。

## 2. Default Rules

- Sub-agent 默认串行。
- 只读检索类任务可并行。
- 写入、审批、同步、备份任务必须串行。
- 长索引任务必须显示书籍级进度。
- 默认不开 web。
- 默认不启用高成本多角色跨书讨论。

## 3. Required Acceptance

任务完成时必须证明：

- 用户知道当前处理对象。
- 失败时用户能看到失败原因。
- 取消不会留下不可解释的半写入用户资产。
- 重启后 running job 能恢复、重排或显示失败。
- token/成本或调用范围可见。

## 4. Rescue Review Questions

- 这个任务是否默认启动多个 LLM stream？
- 是否有移动端内存或电量风险却没有 Gate？
- 取消时是否会写入部分卡片、笔记或同步产物？
- 是否在前台长时间静默运行？
