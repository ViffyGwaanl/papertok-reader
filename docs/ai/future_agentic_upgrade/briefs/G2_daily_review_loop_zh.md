# G2 Brief — 每日回顾循环

> 前置:体验重建期收口;G1 不是前置(可并行)。
> DoD:用户每天收到一条本地通知,点开进入"今日回顾"仪式(3 张卡:你的划线/记忆/知识卡),可标记"记住了/再见到/开卡研讨";次日通知按遗忘曲线复现;真机验收通过。
> 最后更新:2026-07-03

## 为什么(一句话)

读书工具最强留存环(Readwise 验证):**你自己的划线按遗忘曲线回来找你**——数据源(3090 行记忆系统 + Review Inbox)已在库里,缺的只是通知管道和仪式化入口。

## 批次

1. **通知管道**:引入 `flutter_local_notifications`(iOS/Android/macOS 配置),封装为 `lib/service/notification/`(权限请求、定时、点击路由);首次触发时机按用户拍板(默认在用户第一次手动完成回顾后再请求权限,提高 iOS 授权率)。单测:调度/取消逻辑。
2. **回顾选材**:`lib/service/memory/` 上加选材器——每日取 3 条:优先(a) 按间隔重复到期的旧记忆(1/3/7/21 天),(b) 近 7 天新划线,(c) Review Inbox 待处理知识卡各来源混合;纯函数 + 单测。不改记忆存储 schema,间隔状态存新表或 prefs(执行时二选一,ADR 一段进 commit message)。
3. **今日回顾页**:新页面 `lib/page/review/daily_review_page.dart`:3 张卡滑动浏览,每张显示内容+出处(点击跳回书内位置),动作:记住了 / 稍后再见 / 展开研讨(跳 AI Chat 带上下文);做完出一句轻反馈(连续天数)。入口:通知点击 + 首页入口角标。
4. **调度接线**:每晚计算次日是否有到期材料,有则排通知(无材料不发,**宁缺勿滥**);通知文案引用当日第一条划线的前半句(钩子),ARB en+zh。
5. **收尾**:连续天数统计接入统计页;暗色/iPad;真机验收。

## 验收(真机,用户执行)

1. 首次完成一次手动回顾后,系统弹通知权限请求;授权后次日定时收到通知,文案含自己的划线片段。
2. 点通知直达今日回顾;3 张卡可跳回书内原文位置。
3. 标"记住了"的条目短期不再出现;"稍后再见"次日复现。
4. 无到期材料的日子不发通知。
5. 杀进程后调度仍生效(次日通知照发)。

## 红线

- 不改 `lib/service/memory/` 存储 schema 与 `lib/dao/database.dart`(间隔状态放新表/新存储)。
- 通知只用本地,不接推送服务;每日至多 1 条,禁止运营式打扰。
- 回顾页不做成第二个聊天界面;"展开研讨"跳既有 AI Chat。
